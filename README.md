# Sobre o Projeto
O projeto **SIGAA de Bolso** é uma aplicação mobile focada em melhorar a experiência de uso e a acessibilidade dos dados acadêmicos para estudantes e docentes de universidades federais.

# O Problema
O sistema escolar adotado por grande parte das universidades federais (SIGAA) apresenta falhas que impactam negativamente a rotina acadêmica de alunos e professores:
**Instabilidade:** O sistema apresenta quedas e travamentos frequentes, especialmente em períodos de pico, como início de semestre e épocas de prova.
**Ausência de Interface Mobile:** A falta de um aplicativo obriga os usuários a acessarem uma interface web desatualizada e não responsiva pelo celular.
**Dificuldade de Navegação e Burocracia:** Há enorme dificuldade para realizar ações simples, como cadastrar turmas, emitir documentos básicos e alterar dados pessoais.
**Falta de Alertas:** O sistema exige que o aluno faça buscas constantes (entrar no portal repetidas vezes) para verificar se notas foram lançadas ou se aulas foram canceladas, gerando ansiedade e perda de tempo.

# SIGAA de Bolso (App Universitário)

# Principais Funcionalidades

**1. Modo Sobrevivência (Offline):** 
A aplicação fará a sincronização das informações mais críticas no momento em que o usuário fizer o login. Os dados ficarão salvos na memória do dispositivo. 
* O estudante poderá consultar sua grade de horários, o local físico das aulas (ensalamento) e o limite de faltas disponíveis mesmo sem conexão com a internet ou caso o servidor do SIGAA esteja fora do ar.
* A interface será pensada exclusivamente para dispositivos móveis, com navegação fluida e intuitiva.

**2. Olha a Nota!:** 
Um sistema rodando em segundo plano verificará atualizações no perfil do aluno para enviar alertas.
* Alertas automáticos sobre lançamento de novas notas.
* Avisos de cancelamento de aulas postados no mural da turma.
* Alertas preventivos sobre o numero de faltas acumuladas em cada disciplina.

**3. Mestre JM IA (Chatbot):** 
A aplicação contará com um bot equipado com inteligência artificial para auxiliar alunos e professores na resolução de dúvidas operacionais.
* Suporte direto a calouros sobre processos de matrícula, emissão de atestados e trancamento de curso.
* Tradução de termos técnicos e burocráticos do sistema oficial.
* Auxílio a docentes na navegação do sistema para fechamento de diários e consolidação de turmas.
